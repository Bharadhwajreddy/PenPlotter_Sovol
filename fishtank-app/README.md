# Fish Tank: clickable v1

A one-file prototype of Fish Tank, an app where people pitch a business by video and get backers, mentors and help. It runs in any browser with no build step. All people and numbers in it are sample data, and no real money moves.

## Run it

Open `index.html` in a browser.

## Put it online

- **Vercel:** import this repository, set the root directory to `fishtank-app`, and deploy with no framework preset.
- **Netlify or GitHub Pages:** serve the `fishtank-app` folder as a static site.

## What's inside (V3)

One welcome flow (language, phone number, "what do you want to do?"), then a separate app for each kind of user:

- **Business app** (teal): a home screen that changes with the business's stage; voice-first pitching in Telugu, Hindi or English; proof that has to be checked before it counts toward the Fish Score; a circle round shared on WhatsApp; staged payouts against a bill and photo; a repayment calendar with UPI AutoPay; monthly updates; and bank-loan help (MUDRA pack, JanSamarth).
- **Backer app** (gold, phase 2): plain-words cards ("pays monthly", interest marked "not guaranteed"), risk in its own colours, a "Why 81?" Fish Score breakdown, "spread ₹10,000 across 10", and a repayments calendar.
- **Mentor app** and **partner app** (plum): requests and earnings for mentors; candidates and verified listings for franchise brands and banks.
- **Everywhere:** notifications, Listen buttons, Hindi/Telugu on core screens (needs a native-speaker check), and a "Save mobile data" mode.

On a computer the app shows in a phone frame, with a presenter panel to switch users and run demo controls.
